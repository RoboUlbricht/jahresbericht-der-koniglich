# English

Tools and web viewer for processing, indexing, OCR cleanup, AI translation, and browsing historical geological publications of the Royal Hungarian Geological Institute:
* *Jahresbericht der Königlich ungarischen Geologischen Reichsanstalt* (German edition)
* *A Magyar Királyi Földtani Intézet évi jelentései* (Hungarian edition)

---

## Features

- **PDF Text & Image Extraction**:
  - Extracts text page-by-page from digitized PDF volumes using `pdfjs-dist` (stored with `## Page: X` delimiters).
  - Renders fast thumbnail previews (`prepare-thumbnails.js`) and high-resolution JPEG page scans (`prepare-images.js`) using `@napi-rs/canvas`.
- **BSB / MDZ OCR Fetching (`fetch-bsb-text.js`)**:
  - Automatically fetches hOCR OCR data from the Munich Digitization Center (MDZ / Bayerische Staatsbibliothek) API.
  - Fixes typographic quotes, OCR misrecognitions (such as `,,` for `„`), and cleans HTML entities.
- **AI-Powered OCR Normalization (`normalize-de-text.js`)**:
  - Repairs Fraktur/historical German OCR errors, ligatures, and broken hyphenated words page by page using Google Gemini.
- **AI Geological Translation (`de-sk-translator.js`)**:
  - Translates historical 19th-century German geological and mineralogical texts into Slovak using Google Gemini with domain-tailored instructions.
- **Author & Metadata Normalization (`normalize-authors.js`)**:
  - Standardizes author names from ALL-CAPS into standard capitalization.
  - Preserves noble particles (`von`, `v.`, `de`, `van der`), titles (`Dr.`, `Prof.`), and corrects Cyrillic homoglyphs generated by OCR.
- **Markdown Index Generation (`md-index.js`)**:
  - Generates structured Markdown overview documents from `articles.json` with direct links to original digitizations (Google Books, EPA OSZK, etc.).
- **Interactive Web Viewer & Cataloging Tool (`viewer/`)**:
  - **Article Cataloger (`/create-index`)**: Interactive cataloging of articles per volume with AI title extraction, cleanup, and translation.
  - **Scan & Text Viewer (`/show-text`)**: Synchronized side-by-side view comparing original page scan images, German OCR/normalized text, and Slovak translation.

## Installation & Setup

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Configure environment variables**:
   Create a `.env` file based on `.env.example`:
   ```bash
   cp .env.example .env
   ```
   Add your Google Gemini API key:
   ```env
   GEMINI_API_KEY=your_gemini_api_key_here
   MODEL=gemini-3.8-flash
   ```

## Available Scripts

| Script | Command | Description |
| :--- | :--- | :--- |
| **Viewer** | `npm run viewer` | Starts the Express.js local server at `http://localhost:3000` |
| **Extract Text** | `npm run prepare-text <path-to-pdf>` | Extracts text content from PDF to `<name>.txt` |
| **Thumbnails** | `npm run prepare-thumbnails <path-to-pdf> [height]` | Renders page thumbnail previews (default height 300px) |
| **Full Images** | `npm run prepare-images <path-to-pdf> [options]` | Renders high-resolution page scans (options: `--height`, `--quality`) |
| **Fetch MDZ OCR** | `npm run fetch-bsb-text <identifier-or-path> [options]` | Downloads and cleans OCR text from Bayerische Staatsbibliothek |
| **Clean OCR** | `npm run normalize-de-text <path-to-txt> [options]` | Cleans historical German OCR text with Gemini AI |
| **Translate** | `npm run de-sk-translator <path-to-txt> [options]` | Translates German text to Slovak via Gemini AI |
| **Normalize Authors** | `npm run normalize-authors [path-to-articles.json]` | Formats and cleans author names in `articles.json` |
| **Generate Index** | `npm run md-index <path-to-articles.json>` | Generates a Markdown index file |
| **Search Toponyms** | `npm run search-toponyms [options]` | Fast category-based search for Slovak toponyms & mining terms |

# Slovenčina

Nástroje a webový prehliadač na spracovanie, indexovanie, čistenie OCR, AI preklad a prehliadanie historických ročeniek Uhorského kráľovského geologického ústavu:
* *Jahresbericht der Königlich ungarischen Geologischen Reichsanstalt* (nemecké vydanie)
* *A Magyar Királyi Földtani Intézet évi jelentései* (maďarské vydanie)

---

## Hlavné funkcie

- **Extrakcia textu a generovanie náhľadov z PDF**:
  - Extrakcia textu po jednotlivých stranách pomocou knižnice `pdfjs-dist` (s označením `## Page: X`).
  - Generovanie miniatúr (`prepare-thumbnails.js`) a celostránkových JPEG skenov vo vysokom rozlíšení (`prepare-images.js`) pomocou `@napi-rs/canvas`.
- **Sťahovanie OCR z BSB / MDZ (`fetch-bsb-text.js`)**:
  - Automatické sťahovanie hOCR prepisov z mníchovského digitalizačného centra (MDZ / Bayerische Staatsbibliothek).
  - Oprava typografických úvodzoviek, chýb po OCR (napr. `,,` namiesto `„`) a čistenie HTML entít.
- **AI normalizácia a oprava OCR (`normalize-de-text.js`)**:
  - Oprava chýb historického nemeckého fraktúrového OCR, ligatúr a rozdelených slov cez riadky pomocou modelu Google Gemini.
- **AI odborný geologický preklad (`de-sk-translator.js`)**:
  - Preklad nemeckých odborných geologických, stratigrafických a mineralogických textov 19. storočia do slovenčiny pomocou Google Gemini s kontextovými inštrukciami.
- **Normalizácia mien autorov (`normalize-authors.js`)**:
  - Konverzia mien z ALL-CAPS do štandardného tvaru.
  - Správne zachovanie šľachtických častíc (`von`, `v.`, `de`, `van der`), titulov (`Dr.`, `Prof.`) a oprava zámen cyrilických znakov z OCR.
- **Generovanie Markdown indexov (`md-index.js`)**:
  - Tvorba prehľadných štruktúrovaných Markdown katalógov z `articles.json` s odkazmi na pôvodné digitalizáty (Google Books, EPA OSZK a pod.).
- **Interaktívny webový prehliadač a katalogizácia (`viewer/`)**:
  - **Katalogizácia článkov (`/create-index`)**: Interaktívne spracovanie článkov ročníka, extrakcia názvov a ich automatický AI preklad.
  - **Prehliadač textov a skenov (`/show-text`)**: Synchrónne zobrazenie skenu strany, nemeckého OCR/normalizovaného textu a slovenského prekladu vedľa seba.
