Katalogizácia článkov

Editor a katalogizátor bibliografických záznamov. Umožňuje párovanie čísla strany s PDF stranou cez miniatúry, náhľad OCR textu, normalizáciu mien autorov a AI preklad staronemeckých a maďarských vedeckých názvov.

CLI Pipeline
Extrakcia textu (OCR)

Dávková extrakcia textových vrstiev a OCR blokov z PDF súborov ročníkov. Ukladá štruktúrovaný text rozdelený po stranách do .txt.

npm run prepare-text
src/prepare-text.js
CLI Pipeline
Generovanie miniatúr

Hromadné vykresľovanie stránok z PDF do optimalizovaných PNG miniatúr pre plynulý náhľad a navigáciu v rozhraní katalogizátora.

npm run prepare-thumbnails
src/prepare-thumbnails.js
CLI Pipeline
Generovanie JPG snímok

Vykreslenie stránok v plnom rozlíšení do JPG formátu pre detailné čítanie textu, geologických profilov a litografických tabúľ v modálnom okne.

npm run prepare-images
src/prepare-images.js
CLI / Algoritmus
Normalizácia autorov

Automatická kontrola a unifikácia zápisov mien bádateľov v databáze (formátovanie iniciál, historické predložky von, de, van).

npm run normalize-authors
